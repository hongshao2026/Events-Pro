## 实际覆盖的用户操作

- 使用正常原生界面打开 KPC 赛程与详情，Day 1A/1B 设参加、Day 1C 设关注；自选分类数量为 3/2/1。
- 按起始组合计参加预算 ₩1,600,000；关注不计入预算。日历为三条起始活动与一条条件 Final 续赛，没有重复新增。
- 生成完整自选表格 PNG 并打开图片预览，系统菜单显示正确文件名、PNG 格式和实际保存操作；取消后保留预览、恢复按钮，再次分享仍显示正确内容。
- 参赛 JSON 与设置 JSON 分别打开原生菜单，显示当前文件名、JSON 格式及系统保存操作，随后取消；菜单实际显示 576 / 506 字节，不把预览大小当作已验证备份内容。
- 取消后既有自选和预算仍在；同次安装终止并重启后仍保留。
- 实际重新编译原生构建 2、同 ID 覆盖安装，不卸载、不恢复、不重新创建选择；独立 XCTest 读取既有自选、预算及条件日历，并再次核对已安装原生构建号为 2。容器路径改变只记录，不作为数据丢失判据。

每轮只创建和清理该工具自己的独立模拟器，没有操作已有的 iPhone 18 Pro 模拟器或真实设备。没有注入 JS、存储或模拟插件；测试目标不参与 Archive。免费、离线与登录默认关闭保持不变。
