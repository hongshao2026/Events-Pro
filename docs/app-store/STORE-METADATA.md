## 简体描述

赛事自选帮助你查看扑克赛事安排，比较场次时间与报名费，并整理自己的参赛计划。

- 按地区浏览赛事系列，查看正在进行与即将到来的安排。
- 置顶近期关注的一场赛事，快速返回完整赛程。
- 按日期、报名费区间和赛事类型筛选，查看开赛与报名截止资料。
- 将参加或关注的场次加入个人日历与自选表格。
- 按原币统计参赛预算，并使用个人保存的参考汇率查看估算金额。
- 在设备上导出完整表格图片，通过 iOS 系统菜单存储或分享。
- 导出与恢复本机 JSON 备份，无需注册账户。

本版本主界面为简体中文，赛事名称保留原文。个人计划保存在本机，不会自动跨设备同步。“参加”仅表示个人计划，不代表已向主办方报名。赛程、参赛资格及费用变更请核对主办方最新资料。

## 繁体描述

賽事自選協助你查看撲克賽事安排、比較場次時間與報名費，並整理個人參賽計畫。

- 依地區瀏覽賽事系列，查看正在進行與即將到來的安排。
- 置頂近期關注的一場賽事，快速返回完整賽程。
- 依日期、報名費區間及賽事類型篩選，查看開賽與報名截止資料。
- 將參加或關注的場次加入個人日曆與自選表格。
- 依原幣統計參賽預算，並以個人儲存的參考匯率查看估算金額。
- 在裝置上匯出完整表格圖片，透過 iOS 系統選單儲存或分享。
- 匯出及還原本機 JSON 備份，無須註冊帳號。

本版本主介面為簡體中文，賽事名稱保留原文。個人計畫儲存在本機，不會自動跨裝置同步。「參加」僅表示個人計畫，不代表已向主辦單位報名。賽程、參賽資格及費用變更請確認主辦單位最新資料。

## 截图顺序

1. 赛事目录：正在进行/即将到来与单场置顶。
2. 赛事场次：开赛、截买、信息三栏及下拉筛选。
3. 我的日程：个人参加/关注的日历与当天安排。
4. 我的自选：横向完整表格和原币预算。
5. 完整图片预览与系统分享入口。

使用测试安排而非真实个人记录；展示能在该构建中复现的操作。最终截图应来自真机或模拟器，并使用苹果当时接受的尺寸。当前浏览器 QA 图片只用于开发检查，不能作为“真机已验证”的证据。
