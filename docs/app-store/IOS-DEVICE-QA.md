# iOS 真机验收记录模板

状态：未执行。桌面 Chromium/WebKit 与模拟原生桥测试不能替代以下记录。

记录设备型号、iOS 版本、Xcode 版本、源码提交、应用版本/构建号、测试日期、执行人及每项实际结果。

- 首次启动、系统分享后返回、后台恢复、强制退出重启，个人选择与设置正确。
- 飞行模式可查赛事、筛选、改个人分类、看日历及预算、生成图片。
- 刘海/灵动岛、底部指示条、横竖屏、较小 iPhone、软键盘显示时，控件与完整金额可读可操作。
- 文件导出可存入“文件”；参赛备份与设置备份分别恢复；取消及无效文件不改数据。
- 图像可通过系统分享；取消保留预览；用户选择目标后才发送；再分享成功；缓存文件清理。
- 若系统提供存储到照片，验证仅添加照片的说明及授权/拒绝路径，拒绝后可继续使用“文件”，不读取已有照片。
- 外部官网在浏览器打开；内置 PDF 可存储/分享；断网失败可返回本机应用。
- 换设备使用两种 JSON 备份恢复；不声称自动云同步。
- 隐私/帮助/使用说明可离线阅读，简繁切换、邮件联系和公开政策 URL 可用。
- 系统设置的应用页面中，版本与开源许可入口可读；长许可证可完整滚动；Archive 包含 Settings.bundle 与完整依赖声明，Swift 解析版本与来源记录一致。
- 清除数据先确认，取消保留，确认移除计划和设置；已导出文件仍存在。
- VoiceOver 能读到赛事完整名、按钮和金额，焦点返回正确；动态文字、减少动态效果、大文字/放大检查。
- 生成 Archive，并检查完整 Privacy Report、SDK/API 声明、版本、签名和应用图标。
- TestFlight 安装与更新：原记录保留；分享、文件导入以及最后实际上传的构建再次验证。
